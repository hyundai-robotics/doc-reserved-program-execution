# 2.2 程序计划执行寄存器

程序计划执行寄存器允许您确认、修改、插入或删除计划程序。这可在程序计划执行设置中的应用寄存器计数设置为“20”或“1”时使用。从面板选择窗口选择 `[Program Schedule]`。

![](../_assets/image5.png)

- 编辑  
要更改当前位置信息中的计划程序，请点击“编辑”按钮并输入所需的程序编号。

- 插入  
点击“插入”按钮并输入所需的保留程序编号，以在当前位之后保留一个新程序。

- 删除  
定位到您想要删除的保留程序编号，然后点击“删除”按钮以从寄存器中移除该程序编号。

  

`[注意]`
- 在远程模式下无法执行。
